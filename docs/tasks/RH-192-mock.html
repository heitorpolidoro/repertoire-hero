RH-192 Specification Assertions

  • One song record per (version, context): Setlists sharing a song share the record and file bytes without duplicating cache space.
  • Protection Rule: Removing a setlist deletes only songs not held by another setlist and not marked individually downloaded.
  • Pure v6 conversion: Migrates stored legacy records on device with throwing fetch without requiring internet access.
  • Unreachable playlist protection: Network failure reading playlist details leaves existing offline copy unchanged.
