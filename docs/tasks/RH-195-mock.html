1. The /offline Screen (OfflineSetlists)

When a cold offline navigation lands on /offline, downloaded setlists appear below the "You are offline" card in stored order. Stored songs link to Fast View and write the setlist queue to sessionStorage; missing songs show the dashed Not on this device mark and are not links.

Key Rules Verified (RH-191 Rules 30 & 31)

  • Statically prerenderable: /offline has no server-side dynamic calls; OfflineSetlists loads from IndexedDB after mount.
  • Card-only when empty: With no downloaded setlists, OfflineSetlists returns null so only [data-testid="offline-shell"] renders.
  • Full queue written on click: Clicking a stored song writes every entry of that setlist (including missing songs) to sessionStorage["song-queue"] with originHref: "/offline", the setlist's playlistName, and its owner context.
  • Missing songs: Songs whose songRecordId(versionId, bandId) is not stored render with a dashed border, Not on this device, and no link.

2. Fast View Document Caching on Song Save (Rule 35)

Saving a song fetches its Fast View HTML document and stores it in OFFLINE_PAGE_CACHE (rh-offline-pages-v1) on HTTP 200. A non-200 response or network error is logged via logger.error and never fails or rolls back the song save.
