RH-102 — Replace the cycling status badge with the four-note control

Four quarter notes with the stage name beside them. Tapping a note sets that stage in either direction; tapping the note that is already current drops one stage — from the first note, that clears the status back to unassessed. Zero notes filled is unknown. The control is monochrome — a filled note is the plain foreground grey, an unfilled note a muted grey outline; no stage colour appears anywhere in it. Every enabled control on this page is live: tap the notes.

1. All five states, at both sizes

Row size (~17px) is the dashboard and playlist row. Stage size (~32px) is the Fast View.
