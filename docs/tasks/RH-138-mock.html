2. Correction form - the Links block (other fields unchanged, omitted here)

Links - decide each row

An untouched row sends nothing. An edited row sends only the changed fields of that row. A removed row sends one removal. There is no "add a row" here.

3. Admin moderation queue - Question: how does the reviewer decide link rows?

Same card, two ways to decide. The spec picks A: one verdict per link row, so one bad removal does not sink a good edit. B keeps one verdict for the whole card, as the queue does today. Answer with one letter.
