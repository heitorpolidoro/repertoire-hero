Removed: the upload destination question

In band context the upload used to stop and ask. Click Upload under BEFORE to see it. It is deleted, together with needsDestinationChoice, resolveUploadTarget, resolveDeleteTarget, mergeTabs, entryTabOrigin and the TabOrigin / MergedTab types.

The band-owned files

Option A (what the spec does). Band-owned tab rows are dropped by the migration, with their annotations. Nothing records who uploaded them, so there is no musician to give them to. Their file URLs are written to abandoned_blobs so the loss is recoverable by hand.

Option B. Each band-owned file becomes one song_files row per current member of that band, all pointing at the same stored object. Nobody loses a chart they relied on; the cost is rows manufactured for people who never uploaded anything, and copies that no longer track a membership that changes.
