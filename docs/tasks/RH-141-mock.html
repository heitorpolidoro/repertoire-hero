RH-141 - Grouped correction review (admin moderation)

Same data in both layouts. Competing corrections to one field are grouped; identical proposals collapse into one option with a count. Choosing an option approves it and closes the others in the same act (they become "superseded", not "rejected").

Question 1 - How is the queue organised? (answer: A or B)

A - one card per song, with a section per contested field inside it (the admin sees everything wrong with one song at once). B - one card per field (the admin works through contested fields one after another; the song name is in the card header). The spec currently picks A.
