    4 · What a non-admin loses

    • Cannot set a band row's status, from any screen. The server refuses it.
    • Cannot edit a band row through the song edit modal, because that modal writes status, tags and key in one statement. The inline tag editor still works.
    • Everything personal is untouched; so is reading, adding, removing and writing lyrics on a band row.
    • On Fast View the dropdown still looks live for a member and reports "Failed to update status" on tap. Deliberate: RH-102 replaces that control.
